# Music-Genre-Classification-GTZAN
Music genre classification using CNN and Traditional ML models on GTZAN dataset
 Initial performance metrics
Testing in the first phase for all ten genres gave excellent results. In the CNN Mel-spectrogram model, we recorded an accuracy rate of 85%, whereas in the CNN MFCC model, the result was around 70%. On the machine learning front, the extended set of features always gave us a better classification than the basic models.
Audio files have not been included due to size limitations; they are located in the features folder.
